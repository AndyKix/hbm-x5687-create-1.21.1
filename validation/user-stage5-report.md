# Отчёт пользователя — 31 октября 2026

Пользователь передал сообщение тестировщика обычного мира:
«трикситовая руда в печь не добавляется», «в целом всё», «только трикситовая».
Отдельно уточнил: отчёт относится только к обычному миру, Create отдельно
ещё не подтверждён. Затем сообщил: «create проверим после некст патча».

Это общий положительный отчёт о срезе 0.5.0 обычного мира, без перечисления
каждого результата A29–A46. Пункты не отмечены индивидуально подтверждёнными;
A40 о неплавящейся трикситовой руде потребовал пояснения исходного поведения.

Аудит официального X5687 подтвердил: печь не принимает ore_tikite;
в ней плавится crystal_trixite. Для руды нужны будущие центрифуга/кристаллизатор.
В 0.6.0 добавлена подсказка, механика печи не изменена. Список всех неподтверждённых
Create-пунктов сохранён, к нему добавлены новые B22–B28.
