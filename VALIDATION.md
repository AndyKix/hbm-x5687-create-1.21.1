# Проверки

## 0.3.0-stage3 — 30 октября 2026

Minecraft 1.21.1 / NeoForge 21.1.264 / Create 6.0.10 / Java 21.
`./gradlew build runGameTestServer --console=plain`: все **24 обязательных теста прошли**.
13 прежних сценариев и 11 новых:

1. Настоящее размещение BlockItem: поворот во все четыре стороны, расход одного
   предмета, все 8 частей и единый контроллер; разборка с одним выпадением.
2. Занятое место в объёме 2×2×2 не заменяется, предмет не тратится.
3. Плавка ровно 160 тиков; предзагрузка угля даёт 2000, простой / полный или
   несовместимый выход не расходует топливо и не уничтожает предметы.
4. Очередь двух топливных слотов, древесный уголь без бонуса, ведро после лавы.
5. Реальные серверные тики до / после NBT: восстанавливаются инвентарь,
   прогресс и запас топлива; одна руда даёт один слиток, расход ровно 160.
6. Все 8 частей и 6 сторон предоставляют корректную автоматизацию;
   вход/топливо не извлекаются, выход не принимает вставку, улучшения не доступны.
7. Настоящие воронки через proxy-части подают сырьё/топливо и выгружают результат.
8. Разрушение каждой из восьми частей: ровно один предмет печи и один комплект
   инвентаря; после удаления capability отсутствует.
9. Исходный крафт и shift-click: маршрутизация сырья / топлива / результата,
   отсутствие потерь, заблокированный слот улучшений.
10. Сохранение учёта опыта, выдача 3 XP за титановую руду ровно один раз;
    топливные счётчики 200000 корректно проходят signed-short представление меню.
11. Реальный BearingContraption Create отвергает печь и сохраняет её инвентарь.

Лог: `validation/gametest-stage3.log`.

`./gradlew runClient -PclientSmoke --console=plain`: **BUILD SUCCESSFUL**,
`HBM CLIENT SMOKE PASSED`. В отдельном новом мире настоящий клиент:

- загрузил все 8 комбинаций поворота / включения исходной OBJ-модели;
- отобразил работающую многочастную печь;
- получил меню, открытое сервером, и синхронизацию входа, обоих топливных
  слотов, остатка топлива, прогресса и состояния работы;
- завершил работу с сохранением мира.

Лог `validation/client-stage3.log`; визуально просмотрены
`validation/hbm-stage3-world.png` и `validation/hbm-stage3-menu.png`.
Тестовый код исключён из пользовательского JAR. Для повторения клиентского
теста создаётся новый отдельный мир с префиксом `hbm-stage3-smoke-`.

Эта проверка не заменяет длительную игру, загрузку мира после полного закрытия
процесса, несколько одновременно подключённых игроков, внешний dedicated server
или модпак. Жидкости / энергия / улучшения / загрязнение ещё отсутствуют;
подробности и адаптации — `STAGE3_MAPPING.md`. Предупреждение о mip-текстуре
исходного размера 156×68 зафиксировано; ошибки загрузки модели не обнаружены.

## 0.2.0-stage2 — 30 октября 2026

Minecraft 1.21.1, NeoForge 21.1.264, Create 6.0.10 (Maven build 281),
Ponder 1.0.82, Flywheel 1.0.6, Temurin JDK 21.0.13.

`./gradlew build runGameTestServer --console=plain` — **BUILD SUCCESSFUL**.
Все **13 обязательных серверных GameTests прошли**:

1. Прессование стального слитка реальным прессом Create с вращением.
2. Такой же сценарий для титана.
3. Такой же сценарий для свинца.
4. Упаковка / распаковка трёх металлов без потери или дублирования.
5. Захват, создание сущности, поворот, NBT и восстановление обычных блоков
   HBM в конструкции Create. Длительные тики движения не проверяются.
6. Реальные печи и плавильные печи переплавляют обе руды с расходованием входа.
7. Кирка подходит для руд, пустая рука не подходит; таблица выпадения возвращает
   один блок руды, а не сырой металл.
8. Смеситель Create с настоящей кинетической связью через шестерню и горелкой,
   заправленной углём, расходует железо и уголь и выдаёт один слиток стали.
9. Без нагрева при достаточной скорости сталь не производится, входы сохранены.
10. Без вращения при нагретой горелке сталь не производится, входы сохранены.
11. Руды добавлены в генерацию Overworld-биома и отсутствуют в Nether-биоме.
12. Размещение сохраняет частоту X5687 и диапазон высот центров жил 5…34.
13. Настоящий зарегистрированный генератор создаёт руду в подготовленном камне,
    не заменяет базальт и повторяет рисунок при равных seed и исходных объёмах.

Лог: `validation/gametest-stage2.log`. Генератор проверен на подготовленном
объёме и через регистрацию биомов; разведка большого естественного мира,
измерение плотности руд и клиентская проверка новых текстур не проводились.
Проверка руд не утверждает одинаковый рисунок жил на одном seed между 1.7.10
и 1.21.1. Машины HBM и их работа при движении ещё отсутствуют.

Пользовательская проверка первого этапа зафиксирована в
`validation/user-stage1-report.md`: скриншоты подтверждают клиентский запуск,
вкладку / иконки материалов и крафт стального блока в обе стороны.
Остальные клиентские сценарии этими изображениями не подтверждаются.
