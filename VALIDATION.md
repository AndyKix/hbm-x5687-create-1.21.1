# Проверки

Текущая версия 0.1.1-stage1 проверена на Minecraft 1.21.1, NeoForge 21.1.264, Create 6.0.10
(Maven build 281), Ponder 1.0.82, Flywheel 1.0.6, Temurin JDK 21.0.13.

`./gradlew build runGameTestServer --console=plain` — **BUILD SUCCESSFUL**.
Все пять обязательных серверных GameTests прошли:

1. Реальный пресс Create на вращении изготовил стальную пластину из слитка HBM.
2. Такой же сценарий для титана.
3. Такой же сценарий для свинца.
4. Крафт девяти слитков в блок и обратно сохранил количество всех трёх материалов.
5. Для каждого материала Create собрал конструкцию с блоком HBM, создал
   сущность конструкции, принял поворот на 90°, сериализовал данные в NBT,
   загрузил их и вернул блок в мир при разборке.

Последний тест выполняет вызовы поворота и сохранения последовательно;
длительный полёт, тики движения и визуальная анимация им не проверяются.
Этот тест относится к обычным блокам, **не к работающим машинам**.

Дополнительно: все 48 JSON-файлов ресурсов прочитаны без ошибок;
хеши девяти перенесённых текстур совпали с X5687. Рецепты и теги
успешно загрузились на сервере. Отчёт финального запуска сохранён
в `validation/gametest-server.log`.

Первый запуск теста конструкции обнаружил пропуск создания сущности Create
в самом тесте. После восстановления полного жизненного цикла все пять
тестов прошли. Сетевой таймаут сервиса ключей Mojang в первом запуске
не был причиной отказа теста и не повторился в успешном запуске.

Клиентская визуальная проверка, обычный выделенный сервер с игроками,
модпаки, нагрузочные тесты и профилирование не выполнялись.
Нет заявлений об ускорении или полной совместимости HBM / Create.

## Совместимость с NeoForge 21.1.264 — 30 октября 2026

Минимальная версия NeoForge снижена с 21.1.265 до 21.1.264. Она задаётся
отдельным свойством `neo_min_version`, которое подставляется в метаданные
JAR. Проект собран против 21.1.264. Команда `./gradlew build runGameTestServer`
завершилась успешно; все 5 обязательных тестов прошли с Create 6.0.10.
Лог: `validation/gametest-neoforge-21.1.264.log`.

Предыдущий релиз 0.1.0-stage1 был проверен на NeoForge 21.1.265;
его исторический лог сохранён в `validation/gametest-server.log`.
Состав игровых механик не изменялся. Клиентская проверка всё ещё требуется.
