# 0.5.0 — природные ресурсы и прямые рецепты

Официальный X5687: `23ef33447280d83d44c1f7bcd3853fe59c0ec1fc`.
Другие современные порты не использованы. Решение пользователя: сейчас
сырьё, руды и прямые рецепты; сложные продукты — вместе с их машинами.
Энергия и жидкости в этой поставке не добавляются.

Каталог `assets/hbm/raw-materials.json`: **75 блоков / 50 предметов**, включая
5 прежних блоков и 3 прежних слитка. Добавлено **70 новых блоков и 47 новых
предметов**; прежние 3 пластины также сохраняются. 36 обычных features,
геология, две глубинные системы и региональный генератор.

| Источник X5687 | Что перенесено |
|---|---|
| `ModBlocks`, `ModItems`, `ItemEnums`, `BlockEnums` | Природные руды, сырьё и достижимые минеральные формы; metadata-варианты получили постоянные отдельные ID |
| `HbmWorldGen`, `WorldConfig.loadConfig`, `DungeonToolbox` | Частоты, размеры, высоты и породы обычных твёрдых ресурсов трёх измерений; native OreFeature и datapack JSON |
| `BlockOre`, `BlockCluster`, `BlockDepthOre`, `BlockResourceStone` | Исходные выпадения, «Удача», «Шёлковое касание», особые распределения фосфора/малахита/александрита |
| `SmeltingRecipes` | Достижимые исходные плавки с сохранёнными количествами и XP; smelting 200 тиков, дополнительная современная blasting-адаптация 100 тиков |
| `MineralRecipes`, `PowderRecipes` | 76 прямых минеральных рецептов и 2 варианта крафта трёх порохов; сложные цепочки не заменены упрощёнными рецептами |
| `FuelHandler` | Лигнит 1200, адский уголь 4800, красный фосфор 6400 тиков; обычная печь и печь HBM |
| `PressRecipes` | Алюминий → пластина через Create; медь HBM использует штатный рецепт медного листа Create |
| `OreDictManager` | Соответствующие общие формы/руды/хосты `c:`; исключения для лития, фосфора и metadata-кусков учтены явно. Специальные адский уголь/фосфор/триксит не помечены как чужая обычная угольная/фосфорная руда |
| `SchistStratum`, `OreLayer3D` | Исходные шумовые формулы гнейса, гематита, боксита и малахита; шум не содержит общих изменяемых буферов для параллельной генерации |
| `OreCave`, `BlockStalagmite` | Асбестовая облицовка пещер, сталактиты/сталагмиты, опоры, отсутствие коллизии и выпадение порошка |
| `DepthDeposit`, `BlockDepth`, `IDepthRockTool` | Ядро/оболочка, ограничение инструмента и 50 тиков для подходящего API; нижние залежи адаптированы к -64 без вскрытия последней плиты бедрока |
| Региональные ветки `HbmWorldGen` | Seed-залежь колтана и фиксированная область австралия |
| `BlockLithium`, `BlockNetherCoal`, `BlockHazardFalling` | Литиевый блок взрывается от соседней воды с исходной силой 15, без огня и выпадения лития; адская руда поджигает на 3 секунды; красный фосфорный блок падает |
| `ItemAlexandrite` | 16 исходных кадров без изменения пикселей; цвет по свету блока у локального игрока через native model overrides |

Параметры жил — [WORLDGEN.md](WORLDGEN.md). Геометрия жил, рельеф и расположение
на одинаковом seed отличаются от Minecraft 1.7.10. Новая генерация выполняется
при создании чанков; обработчика, переписывающего старые чанки при загрузке,
нет. Миграция миров 1.7.10 не реализована.

## Содержимое, которое переносится со своими системами

| Содержимое X5687 | Зависимость |
|---|---|
| Нефть, коренная нефть, газовые пузыри и газоносный сланец | Жидкости/газы, давление, горение и извлечение; не подменены декоративными блоками |
| Кислотные серные пещеры и их образования | Исходная генерация включает серную кислоту; ожидает fluid-систему |
| Коренные буровые залежи, их вкрапления и компоненты | Машины, кислотная добыча и NBT состава; это отдельная система от глубинных пород |
| Металлические порошки, сплавы, реагенты, изотопы | Измельчители, химия, реакторы и соответствующие производственные цепочки |
| Метеоритные, базальтовые, облучённые, обожжённые, шрабидиевые варианты | События, вулканизм, радиация и трансформации |
| Плутониевая руда Незера | Отключена в обычных настройках X5687; её цепочка пока отсутствует |
| Продвинутые инструменты глубинной породы | Контракт блока готов; игровые инструменты и рецепты появятся со своей производственной цепочкой. Обычной киркой эти образования пока не добываются |
| Радиация, выделение газов, отравления, опасности отдельных предметов | Общая система HazardRegistry переносится отдельно. Наличие урана/асбеста/фосфора не означает перенос этих эффектов; готовые контактная руда и литиевый блок перечислены выше |

Криолит, редкоземельные/малахитовые куски, фрагменты колтана/кобальта и
трикситовая руда не получили выдуманных простых путей в обход будущих машин.
У Create могут быть собственные рецепты по общим тегам; это не перенос
HBM-машин. Железная печь HBM остаётся неподвижной.

## Воспроизводимость

`python3 tools/import_all.py /path/to/official-X5687` запускает импортёры
в порядке materials → iron furnace → crates → raw materials. Все проверяют
точный исходный commit. Пути/хеши ресурсов — `raw-material-provenance.json`;
производные кадры александрита явно отмечены как lossless. Их пиксели
проверены независимым декодером ImageIO.

Проверки — `VALIDATION.md`; накопительные инструкции для двух друзей —
`TESTING.md`: новые A29–A46 и B16–B21, старые непроверенные пункты сохранены.
