# HBM → Minecraft 1.21.1

Независимый поэтапный перенос Hbm's Nuclear Tech `1.0.27_X5687` с 1.7.10.
Цель: **Minecraft 1.21.1 / NeoForge / готовый Create**. Другие современные
порты HBM как основа не используются.

## Скачать и установить

[Тестовый релиз 0.2.0-stage2: JAR и исходники](https://github.com/AndyKix/hbm-x5687-create-1.21.1/releases/tag/v0.2.0-stage2)

Требования: Minecraft **1.21.1**, NeoForge **21.1.264**, Create **6.0.10**,
Java **21**. В `mods` нужны полный JAR Create и один JAR нашего HBM.
Ponder, Flywheel и Registrate включены в полный Create; отдельно их
устанавливать не требуется. Старый HBM 1.7.10 вместе с прототипом не ставить.
При обновлении заменить предыдущий JAR HBM, а не добавлять вторую копию.

## Текущий объём

Это начало второго этапа, **не полный HBM и не готовая сборка для сервера**.

- Стальные, титановые и свинцовые слитки, пластины и блоки хранения.
- Титановая и свинцовая руда с оригинальными текстурами.
- Генерация этих руд в биомах Overworld: центры жил на Y=5…34.
  Титан: 8 попыток на чанк, параметр размера жилы 6; свинец: 6 попыток,
  размер 9. Заменяется обычный камень. Это параметры X5687; алгоритм
  формы жил и рельеф Minecraft 1.21.1 отличаются от 1.7.10.
- Руда добывается киркой и выпадает своим блоком. Сырые металлы не добавлены.
- Плавка: одна руда → один слиток. Обычная печь: 200 тиков, плавильная:
  100 тиков, опыт 3.0. Плавильная печь — адаптация для современного Minecraft.
- Сталь через Create: **один железный слиток + один уголь → один слиток стали**
  в нагреваемом смесителе. Это новый путь интеграции с Create по пропорции
  `BlastFurnaceRecipes` X5687, а не перенос собственной доменной печи HBM.
  Горелке требуется отдельное топливо, смесителю — вращение от 32 RPM.
- Пресс Create превращает соответствующий слиток HBM в пластину.
- Девять слитков упаковываются в блок и распаковываются обратно без потерь.
- Русские названия, общие теги `c:`, модели, таблицы выпадения.

Все **13 серверных GameTests прошли**. Подробности — `VALIDATION.md`.
Клиентская проверка второго этапа в обычном мире ещё требуется.

Машины HBM, собственные сети энергии / жидкостей, питание машин от вращения,
их работа на движущихся конструкциях, радиация, реакторы, оружие и взрывы
ещё не перенесены. Остальные руды и материалы X5687 также остаются в плане.

## Что проверить в игре

Использовать **новый обычный тестовый мир**: в уже сгенерированных чанках
руда автоматически не появится. Альтернатива — уйти в ранее не открытые чанки.

1. Проверить две руды во вкладке HBM и найти их примерно на Y=20 в новом мире.
2. Добыть руду киркой; переплавить обе руды в обычной и плавильной печах.
3. Собрать смеситель Create над чашей, поставить под чашей горелку с ифритом,
   заправить её топливом и подать смесителю минимум 32 RPM через шестерню.
4. Положить в чашу один железный слиток и один уголь. Получить один слиток стали.
5. Без нагрева либо без вращения ингредиенты должны оставаться в чаше.
6. Проверить прессование всех трёх металлов, упаковку / распаковку,
   сохранение и загрузку мира, блоки HBM на конструкции Create.

Обычный блок на конструкции и работающая машина на ней — разные механики.
Последняя пока отсутствует. Перенос сохранений Minecraft 1.7.10 не реализован.

## Исходники и сборка

Основа: https://github.com/HbmMods/Hbm-s-Nuclear-Tech-GIT/tree/1.0.27_X5687

Коммит: `23ef33447280d83d44c1f7bcd3853fe59c0ec1fc`. Все 7 232 ресурса
предоставленного JAR совпали с этим тегом. В `provenance.json` — хеши
11 импортированных текстур; в `port-inventory.json` — перечень исходных
Java-файлов и частичных переносов. Авторство и лицензии: `NOTICE.md`,
`LICENSE`, `LICENSE.LESSER`. Соответствие механик описано в `STAGE2_MAPPING.md`.

Для сборки нужен JDK 21:

```sh
./gradlew build
./gradlew runGameTestServer
./gradlew runClient
```

Windows: использовать `gradlew.bat`. Create не включается в итоговый HBM JAR.
Повторный импорт ресурсов из официального checkout X5687:

```sh
python3 tools/import_materials.py /path/to/Hbm-s-Nuclear-Tech-GIT
```
