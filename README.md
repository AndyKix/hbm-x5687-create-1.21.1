# HBM → Minecraft 1.21.1

Независимый поэтапный перенос Hbm's Nuclear Tech `1.0.27_X5687` с 1.7.10.
Целевая связка согласована: **Minecraft 1.21.1 / NeoForge / готовый Create**.

## Скачать первый этап

[Тестовый JAR и исходники — GitHub Release 0.1.1-stage1](https://github.com/AndyKix/hbm-x5687-create-1.21.1/releases/tag/v0.1.1-stage1)

Для теста нужны Minecraft **1.21.1**, NeoForge **21.1.264**, Create **6.0.10**
и JDK / Java **21**. Использовать отдельный тестовый мир. Полный перенос
ещё не завершён; состав прототипа перечислен ниже.

## Текущий объём

Это прототип первого этапа, **не полный HBM**.

- Зарегистрированы стальные, титановые и свинцовые слитки, пластины и блоки.
- Перенесены девять оригинальных текстур и русские названия.
- Добавлены упаковка девяти слитков в блок и обратная распаковка.
- Добавлены три рецепта прессования Create: слиток → пластина.
- Добавлены общие теги материалов `c:`, теги добычи и таблицы выпадения блоков.
- Подготовлены серверные GameTests с настоящим Create: прессование трёх
  металлов, сохранение количества материала при крафте и сборка / NBT /
  разборка конструкции с блоками HBM.

Слитки пока доступны через творческий режим. Руды, генерация мира и
производство стали ещё не перенесены; полноценного выживания нет.
Машины HBM, их питание от вращения, радиация, реакторы, оружие и взрывы
ещё отсутствуют. Проверка обычных блоков на конструкции не означает
поддержку работающих машин на движущейся конструкции.

## Сборка и проверки

Нужен **JDK 21**. Системный Java 8 не подходит.

```sh
./gradlew build
./gradlew runGameTestServer
./gradlew runClient
```

Windows: использовать `gradlew.bat` вместо `./gradlew`.
Gradle скачает Minecraft, NeoForge и Create; Create в итоговый HBM JAR
не включается. Указанные версии зависимостей находятся в `gradle.properties`.
Детали фактически выполненных проверок записываются в `VALIDATION.md`.

Повторный импорт ресурсов из соответствующего официального checkout:

```sh
python3 tools/import_materials.py /path/to/Hbm-s-Nuclear-Tech-GIT
```

## Проверка в клиенте

1. Открыть вкладку «HBM — Прототип переноса» в творческом режиме.
2. Проверить названия, текстуры, размещение и выпадение трёх блоков.
3. На депо под прессом Create положить один слиток HBM; подать вращение
   на горизонтальный вал пресса. Должна получиться одна соответствующая пластина.
4. Приклеить блоки HBM к конструкции Create, собрать и привести её в движение,
   сохранить и загрузить мир, остановить и разобрать конструкцию.
5. Сверить блоки и количество предметов до и после. Клиентская визуальная
   проверка требуется отдельно от серверных GameTests.

Старый JAR для 1.7.10 не устанавливается вместе с этим прототипом.
Перенос сохранений из 1.7.10 не реализован.
