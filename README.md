# HBM → Minecraft 1.21.1

Независимый поэтапный перенос Hbm's Nuclear Tech `1.0.27_X5687` с 1.7.10.
Цель: **Minecraft 1.21.1 / NeoForge / готовый Create**. Другие современные
порты HBM как основа не используются.

## Скачать и установить

[Тестовый релиз 0.4.0-stage4: JAR и исходники](https://github.com/AndyKix/hbm-x5687-create-1.21.1/releases/tag/v0.4.0-stage4)

Требования: Minecraft **1.21.1**, NeoForge **21.1.264**, Create **6.0.10**,
Java **21**. В `mods` нужны полный JAR Create и один JAR нашего HBM.
Ponder, Flywheel и Registrate включены в полный Create; отдельно их
устанавливать не требуется. Старый HBM 1.7.10 вместе с прототипом не ставить.
При обновлении заменить предыдущий JAR HBM, а не добавлять вторую копию.

## Текущий объём

Новая часть переноса: переносимые контейнеры и их хранение на конструкциях Create. **Полный HBM пока не перенесён; сборка остаётся тестовой.**

- Стальные, титановые и свинцовые слитки, пластины и блоки хранения.
- Титановая и свинцовая руда с оригинальными текстурами.
- Генерация этих руд в биомах Overworld: центры жил на Y=5…34.
  Титан: 8 попыток на чанк, параметр размера жилы 6; свинец: 6 попыток,
  размер 9. Заменяется обычный камень. Это параметры X5687; алгоритм
  формы жил и рельеф Minecraft 1.21.1 отличаются от 1.7.10.
- Руда добывается киркой и выпадает своим блоком. Сырые металлы не добавлены.
- Плавка: одна руда → один слиток. Обычная печь: 200 тиков, плавильная:
  100 тиков, опыт 3.0. Плавильная печь — адаптация для современного Minecraft.
- Сталь через Create: **один железный слиток + один уголь → один слиток стали**
  в нагреваемом смесителе. Это новый путь интеграции с Create по пропорции
  `BlastFurnaceRecipes` X5687, а не перенос собственной доменной печи HBM.
  Горелке требуется отдельное топливо, смесителю — вращение от 32 RPM.
- Пресс Create превращает соответствующий слиток HBM в пластину.
- Девять слитков упаковываются в блок и распаковываются обратно без потерь.
- Русские названия, общие теги `c:`, модели, таблицы выпадения.

- Железная печь HBM **2×2×2** с исходной моделью и GUI X5687: плавка за
  **160 тиков**, два топливных слота, сохранение топлива при простое,
  доступ воронок со всех сторон и через любую часть машины.
- Инвентарь, остаток топлива, прогресс и учёт опыта сохраняются в NBT.
  Меню синхронизируется штатными серверными пакетами Minecraft.

- Железный ящик на **36 слотов**, стальной на **54**; исходные текстуры,
  интерфейсы и звуки X5687, крафт из 3 пластин и 5 слитков соответствующего металла.
- Ящики сохраняют содержимое в выпавшем предмете при разрушении и восстанавливают
  его после установки. Воронки, компаратор, имена, Shift-клик и сохранения мира.
- Ящики можно переносить конструкциями Create, открывать во время движения
  и менять их содержимое. После разборки восстанавливается актуальный инвентарь.

Все **37 серверных GameTests прошли**. Проверены настоящие клиентские меню,
сетевые действия с предметами, меню движущегося ящика и полный перезапуск игры
с загрузкой сохранённого мира.
Скриншоты и точные границы проверки — `VALIDATION.md`.

Улучшения и загрязнение железной печи пока отсутствуют; слот улучшений отключён.
Печь временно запрещена к захвату Create, чтобы не переносить частями её
инвентарь. Другие машины HBM, собственные сети энергии / жидкостей, питание
от вращения, работа машин в движении, радиация, реакторы, оружие и взрывы
остаются в плане. У ящиков пока отсутствуют открытие из руки, замки/ключи HBM
и пауки-ловушки. Различия с X5687 — в `STAGE3_MAPPING.md` и `STAGE4_MAPPING.md`.

## Что проверять в игре

Полный список действий и ожидаемых результатов — **[TESTING.md](TESTING.md)**:

- **A. Друг, который тестирует обычный мир и HBM:** материалы, руды, обычная
  плавка, железная печь 2×2×2, оба топливных слота, меню, обычные воронки,
  сохранение/загрузка мира и разборка без потерь.
- **B. Друг, который знает Create:** вращение, прессование, нагреваемое смешивание
  стали, ленты, конструкции и сохранение их состояния.

**Сам Create пока обязателен для запуска HBM**. Группа A
не использует его механизмы, но JAR Create остаётся в `mods`. Полностью
без установленного Create текущий релиз не запускается.

По сообщению пользователя обычный мир **0.3.0, A1–A17 проверен другом**.
В новом отчёте подтверждены крафты ящиков, воронки и **B4/B5** смесителя;
прессование/автоматика со складом подтверждены частично.
По сообщению пользователя связь содержимого разных ящиков (**A28**) перестала
проявляться после перезахода. У разработчика не воспроизвелась; причина пока
не установлена, изменений игрового кода для этого случая не было.
Все пункты Create сохранены; неподтверждённые сценарии, включая движение,
остаются на проверке. Подробности — `validation/user-stage4-report.md`.
Результаты автотестов разработчика приведены отдельно в `VALIDATION.md`.
В каждом следующем релизе публикуются обе группы A/B с ожидаемым поведением,
неподдерживаемыми возможностями и статусами «проверено / не проверено».

Обычный блок на конструкции и работающая машина на ней — разные механики.
Последняя пока отсутствует. Перенос сохранений Minecraft 1.7.10 не реализован.

## Исходники и сборка

Основа: https://github.com/HbmMods/Hbm-s-Nuclear-Tech-GIT/tree/1.0.27_X5687

Коммит: `23ef33447280d83d44c1f7bcd3853fe59c0ec1fc`. Все 7 232 ресурса
предоставленного JAR совпали с этим тегом. В `provenance.json` — хеши
11 текстур материалов; в `iron-furnace-provenance.json` — исходные ресурсы печи; в `port-inventory.json` — перечень исходных
Java-файлов и частичных переносов. Авторство и лицензии: `NOTICE.md`,
`LICENSE`, `LICENSE.LESSER`. Соответствие механик описано в `STAGE2_MAPPING.md`, `STAGE3_MAPPING.md` и `STAGE4_MAPPING.md`.

Для сборки нужен JDK 21:

```sh
./gradlew build
./gradlew runGameTestServer
./gradlew runClient
# Автоматическая клиентская проверка в отдельном новом мире:
./gradlew runClient -PclientSmoke
# Ящики, меню и взаимодействие с конструкцией Create:
./gradlew runClient -PcrateClientSmoke
# Затем повторный запуск сохранённого тестового мира:
./gradlew runClient -PcrateReloadSmoke
```

Windows: использовать `gradlew.bat`. Create не включается в итоговый HBM JAR.
Повторный импорт ресурсов из официального checkout X5687:

```sh
python3 tools/import_materials.py /path/to/Hbm-s-Nuclear-Tech-GIT
python3 tools/import_iron_furnace.py /path/to/Hbm-s-Nuclear-Tech-GIT
python3 tools/import_crates.py /path/to/Hbm-s-Nuclear-Tech-GIT
```
