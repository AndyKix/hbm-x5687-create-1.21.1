# Этап 3: первая машина и инвентарь

Основа только официальный X5687 `23ef33447280d83d44c1f7bcd3853fe59c0ec1fc`.
Это частичное начало этапа 3 и одна базовая машина из этапа 4, не завершение
систем жидкостей / энергии и не полный перенос машин HBM.

|---|---|

| Твёрдость 5, сопротивление 10 | Сохранены, добывается киркой |
| `TileEntityFurnaceIron.baseTime = 160` | Любой актуальный рецепт `minecraft:smelting` за 160 тиков, независимо от его обычного времени |
| Слоты 0,1,2,3,4 | Вход, топливо 1/2, выход, зарезервированное улучшение (отключено) |

## Явные адаптации

- Современные рецепты и компоненты ItemStack; одинаковые компоненты обязательны
  для объединения выхода. Автоматического переноса старых миров 1.7.10 нет.
- Сервер считает производство, клиент получает штатные данные меню. Длинные
  счётчики топлива разделены на пары short, чтобы сетевые пакеты не обрезали их.
- Опыт учитывается по использованным современным рецептам, сохраняется и выдаётся
  один раз при ручном извлечении результата либо разборке. После автоматического
  извлечения опыт остаётся в машине. Старое поведение SlotSmelting при XP≥1
  не воспроизводится: например, титановая руда даёт 3 XP по рецепту, а не 1.
- Вспомогательные блоки вычисляют контроллер из blockstate; отдельные proxy tile
  entities не создаются. Все части имеют столкновение полного блока, как dummy X5687.
- На этапе 3 тег Create `non_movable` запрещает захват всей печи и её частей;
  это предотвращает частичный перенос инвентаря. Работа в движении будет отдельной задачей.
- Оригинальная текстура 156×68 сохранена без изменения пикселей; атлас Minecraft
  предупреждает об ограничении mip-уровня до 2. Подготовка атласа и профилирование
  рендера остаются отдельной задачей; ускорение не заявляется.

## Пока не перенесено

Скоростные улучшения, muffler, загрязнение / particleFX, специальные топлива HBM
(кокс, лигнит, твёрдое, ракетное и balefire), полная таблица старых рецептов,
сети энергии / жидкостей, питание вращением, производство в движении.
Для ещё не перенесённых топлив не заявляются исходные бонусы ModuleBurnTime.
