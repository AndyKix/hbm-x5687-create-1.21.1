# Ручная проверка 0.4.0-stage4 — накопительный список

Два друга проверяют разные части одной сборки; Create установлен у обоих:

- **Друг, который не занимается Create — группа A:** руды, материалы,
  крафты, печи HBM, обычные воронки, сохранение мира и выпадение предметов.
- **Друг, который знает Create — группа B:** вращение, рецепты Create,
  автоматизация и движущиеся конструкции.

Результаты каждого друга записываются отдельно, по номерам A/B.
## Статус ручных проверок на 31 октября 2026

- **0.3.0, A1–A17: пройдены по сообщению пользователя о проверке друга.**
  Это внешний отчёт, не новая самостоятельная проверка разработчиком.
- **B1–B8: друг по Create ещё не проверял.** Все прежние пункты сохранены ниже.
- **Новое в 0.4.0: A18–A27 и B9–B15 — ожидают проверки друзьями.**
  Старые пункты полезно повторить как проверку совместимости после обновления.
- Автотесты разработчика и клиентские проверки записаны в `VALIDATION.md`;
  они не меняют статусы ручных проверок друзей.
Автотесты разработчика и сообщения тестировщика учитываются отдельно.

## Подготовка

Minecraft 1.21.1, NeoForge 21.1.264, Java 21, полный Create 6.0.10,
один HBM JAR **0.4.0-stage4**. Предыдущий JAR HBM заменить.

**Create остаётся обязательной зависимостью.** «Без механизмов Create» ниже
означает обычные блоки, печи и воронки Minecraft плюс HBM. Удалять JAR Create
нельзя: самостоятельный запуск HBM без установленного Create этим релизом
не поддерживается и не считается выполненной проверкой.

Использовать отдельный новый обычный мир или новые чанки существующего
тестового мира: генерация руд не добавляется в ранее открытые чанки.
Для ящиков можно использовать прежний тестовый мир 0.3.0: в этой обнове генерация руд не менялась.
Для подготовки можно брать предметы в творческом режиме; выпадение проверять
в выживании железной киркой. Крупные серверные сборки и несколько игроков
остаются отдельной проверкой.

Материалы для A18 можно взять из творческого инвентаря: знать механизмы Create
этому другу не нужно. Проверка производства пластин остаётся у друга по Create.
В 0.4.0 ящики открываются после установки в мире; открытие прямо из руки,
замки/ключи HBM и пауки-ловушки пока не перенесены.

Дополнительно: если выход печи заполнился, вход не должен расходоваться,
а запас топлива — уменьшаться. Лава после использования оставляет пустое
ведро в топливном слоте; оно забирается вручную, воронка его не извлекает.
В творческом режиме выпадение предмета печи при разрушении не ожидается.

Сталь и пластины можно взять из творческой вкладки для A1/A2/A17.
Получение стали и пластин через механизмы относится к группе B: отдельный
ванильный рецепт их производства и собственные доменная печь/пресс HBM
пока не перенесены. Радиация, энергия, жидкости, реакторы, оружие, улучшения
и загрязнение печи также остаются в плане и не входят в критерии этого релиза.

Уголь в чаше — ингредиент стали и **не заправляет горелку**. Нужна отдельная

уголь; железный самородок и древесный уголь этот рецепт не заменяют.
Андезит + железный самородок работают без нагрева и не подтверждают B4.

## Как прислать результат

Указать версию HBM/NeoForge/Create и для каждого пункта A/B поставить
«работает», «не работает» или «не проверяли». Для сбоя — номер пункта,
действия, ожидаемое/полученное, скрин всей установки; при вылете —
`logs/latest.log` и соответствующий файл из `crash-reports`.
Непроверенные пункты и сообщения о похожих рецептах не считать подтверждением.
