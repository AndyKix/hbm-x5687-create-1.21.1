# Ручная проверка 0.3.0-stage3

Два друга проверяют разные части одной сборки; Create установлен у обоих:

- **Друг, который не занимается Create — группа A:** руды, материалы,
  крафты, печи HBM, обычные воронки, сохранение мира и выпадение предметов.
- **Друг, который знает Create — группа B:** вращение, рецепты Create,
  автоматизация и движущиеся конструкции.

Результаты каждого друга записываются отдельно, по номерам A/B.
По уточнению пользователя ручные проверки Create пока не считаются проведёнными.
Автотесты разработчика и сообщения тестировщика учитываются отдельно.

## Подготовка

Minecraft 1.21.1, NeoForge 21.1.264, Java 21, полный Create 6.0.10,
один HBM JAR 0.3.0-stage3. Предыдущий JAR HBM заменить.

**В 0.3.0 Create — обязательная зависимость.** «Без механизмов Create» ниже
означает обычные блоки, печи и воронки Minecraft плюс HBM. Удалять JAR Create
нельзя: самостоятельный запуск HBM без установленного Create этим релизом
не поддерживается и не считается выполненной проверкой.

Использовать отдельный новый обычный мир или новые чанки существующего
тестового мира: генерация руд не добавляется в ранее открытые чанки.
Для подготовки можно брать предметы в творческом режиме; выпадение проверять
в выживании железной киркой. Крупные серверные сборки и несколько игроков
остаются отдельной проверкой.

| A2 | Для стали, титана и свинца скрафтить блок из 9 слитков, затем распаковать | Ровно 1 блок и обратно ровно 9 слитков; без исчезновения или размножения |
| A3 | Найти титан и свинец в новых чанках Overworld, ориентир Y≈20 | В мире встречаются обе руды; поиск одной жилы не измеряет частоту генерации |
| A4 | Добыть обе руды в выживании киркой | Выпадает сам блок руды; выпадение пустой рукой не ожидается |
| A5 | По одной руде переплавить в обычной печи и плавильной печи Minecraft | В каждом случае расходуется 1 руда и появляется 1 соответствующий слиток; обычная печь 200 тиков, плавильная 100 |
| A6 | Скрафтить железную печь HBM: `III / IFI / BBB`, I — железный слиток, F — обычная печь, B — каменные кирпичи | Получается 1 железная печь; нужны 5 слитков, 1 печь и 3 каменных кирпича |
| A7 | Поставить печь при свободном объёме 2×2×2; повторить при разных направлениях взгляда | Печь занимает 8 блоков, поворачивается; модель целая, без отсутствующих текстур |
| A8 | Занять один из необходимых блоков объёма камнем и попробовать поставить печь | Установка не проходит, камень не заменяется, предмет печи не тратится |
| A9 | Открыть печь нажатием на разные части | Открывается один общий инвентарь; вход сверху, два топлива снизу, выход справа; слот улучшений отключён |
| A10 | Переплавить титан, свинец и ванильную железную руду в печи HBM | Каждый вход даёт соответствующий результат обычной плавки за 160 тиков (около 8 секунд при 20 TPS); полоски прогресса/топлива обновляются |
| A11 | Положить топливо отдельно в первый, затем во второй слот; проверить уголь и древесный уголь | Оба слота работают, при наличии двух сначала расходуется первый; обычный уголь даёт 2000 рабочих тиков, древесный 1600 |
| A12 | Оставить топливо в печи без подходящего входа | Одна единица может заранее перейти в запас топлива, но полоса при простое не уменьшается. Это ожидаемая предзагрузка X5687 |
| A13 | Проверить Shift-клик сырья/топлива в меню и результата обратно в инвентарь | Предметы попадают в правильные слоты, не пропадают; в выход и слот улучшений вставка запрещена |
| A14 | Подать сырьё и топливо обычными воронками, выгружать результат снизу; проверить подключение через вспомогательные части | Производство работает, выгружается только результат; сырьё и топливо не вытягиваются наружу |
| A15 | Начать плавку нескольких руд, выйти из мира, полностью закрыть игру, запустить её и вернуться | Предметы, запас топлива и прогресс сохранены; плавка продолжается, результат не дублируется |
| A16 | В выживании железной киркой сломать сначала основную, отдельно в другой установке вспомогательную часть печи с содержимым | Исчезают все 8 частей, выпадает ровно 1 предмет печи и всё оставшееся содержимое; невидимых препятствий нет |
| A17 | Поставить/сломать блоки хранения, сохранить мир и вернуться | Текстуры и блоки сохраняются; в выживании подходящим инструментом выпадает соответствующий блок |

Дополнительно: если выход печи заполнился, вход не должен расходоваться,
а запас топлива — уменьшаться. Лава после использования оставляет пустое
ведро в топливном слоте; оно забирается вручную, воронка его не извлекает.
В творческом режиме выпадение предмета печи при разрушении не ожидается.

Сталь и пластины можно взять из творческой вкладки для A1/A2/A17.
Получение стали и пластин через механизмы относится к группе B: отдельный
ванильный рецепт их производства и собственные доменная печь/пресс HBM
пока не перенесены. Радиация, энергия, жидкости, реакторы, оружие, улучшения
и загрязнение печи также остаются в плане и не входят в критерии этого релиза.

## B. Для друга, который знает Create

| № | Действия | Ожидаемый результат |
|---|---|---|
| B1 | Собрать привод, шестерни и смеситель/пресс, для проверки подать 64 RPM | Механизмы получают вращение, при отключении привода останавливаются |
| B2 | Прессом Create обработать по одному слитку стали, титана и свинца HBM | Каждый слиток даёт ровно одну соответствующую пластину |
| B3 | Подавать слитки к прессу лентой, забирать пластины | Автоматизация не теряет и не дублирует предметы |
| B4 | Смеситель над чашей, под чашей горелка с ифритом; отдельно заправить горелку через ПКМ углём; в чашу бросить 1 железный слиток и 1 обычный уголь | При достаточном вращении (от 32 RPM) получается 1 стальной слиток, оба ингредиента расходуются |
| B5 | Повторить B4 без заправки горелки, затем с нагревом, но без вращения | Сталь не производится, ингредиенты в чаше сохраняются |
| B6 | Приклеить блоки хранения стали/титана/свинца к конструкции на механическом подшипнике; собрать, повернуть, остановить и разобрать | Блоки возвращаются без потерь и дублирования |
| B7 | Выйти из мира с собранной конструкцией, закрыть игру и вернуться; затем разобрать | Состав и состояние конструкции сохраняются; блоки не пропадают |
| B8 | Попробовать захватить железную печь HBM конструкцией Create | Захват отвергается; печь, предметы и запас топлива остаются в мире |

Уголь в чаше — ингредиент стали и **не заправляет горелку**. Нужна отдельная
порция топлива самой горелке. Для стали нужны полный железный слиток и обычный
уголь; железный самородок и древесный уголь этот рецепт не заменяют.
Андезит + железный самородок работают без нагрева и не подтверждают B4.

B6/B7 касаются обычных блоков хранения. Перемещение и работа самой печи,
её питание вращением и интеграция сетей HBM ещё не реализованы.

## Как прислать результат

Указать версию HBM/NeoForge/Create и для каждого пункта A/B поставить
«работает», «не работает» или «не проверяли». Для сбоя — номер пункта,
действия, ожидаемое/полученное, скрин всей установки; при вылете —
`logs/latest.log` и соответствующий файл из `crash-reports`.
Непроверенные пункты и сообщения о похожих рецептах не считать подтверждением.
