# Второй этап: соответствие X5687

Взяты исходники официального тега 1.0.27_X5687. Код других портов не применяется.

| Поведение | Источник X5687 | Решение в 1.21.1 |
|---|---|---|
| Названия, текстуры, твёрдость двух руд | ModBlocks.java, ore_titanium / ore_lead | Оригинальные текстуры, соответствующие идентификаторы, твёрдость 5 |
| Выпадение руды блоком | BlockGeneric → BlockBase → Block | Один блок, без сырых металлов и множителя Fortune |
| Обычная плавка 1:1, 3 XP | crafting/SmeltingRecipes.java | Сохранены вход, выход и опыт; 200 тиков обычной печи |
| Плавильная печь Minecraft | В 1.7.10 отсутствует | Дополнительная современная обработка тех же руд за 100 тиков |
| Частота Ti 8, Pb 6 | config/WorldConfig.java | Значения по умолчанию в placed_feature datapack |
| Размеры Ti 6, Pb 9 | lib/HbmWorldGen.java | Передаются современному OreFeature |
| Высота minHeight=5, variance=30 | world/generator/DungeonToolbox.java | Uniform 5…34 включительно; это центры жил |
| Замена Blocks.stone | DungeonToolbox.generateOre | BlockMatchTest для minecraft:stone; глубокосланцевые варианты не выдумываются |
| Генерация Overworld | HbmWorldGen | NeoForge biome modifier для #minecraft:is_overworld |
| IRON + COAL → 1 steel | inventory/recipes/BlastFurnaceRecipes.java | Интеграционный рецепт нагретого смесителя Create: железный слиток + уголь → 1 сталь |

Алгоритмы генерации и биомы платформы изменились. Идентичные жилы на одном
seed между версиями не обещаются. Руды появляются только при новой генерации
чанков; ретрогенерация не реализована. Биомная область #minecraft:is_overworld
следует современным тегам; необычные измерения других модов с теми же биомами
потребуют отдельной проверки.

Доменная печь HBM не перенесена. Остальные варианты IRON (пластины / пыль),
кокс, обогащённые выходы из руды и прочие рецепты этой машины не объявляются
перенесёнными. Нагретый смеситель — явно выделенный путь интеграции с Create.
